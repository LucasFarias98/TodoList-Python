# TodoList-Python
Lista de Tarefas em Python (Console)
📝 Lista de Tarefas em Python (Console)
Um pequeno projeto de lista de tarefas (to‑do list) feito em Python, rodando direto no terminal.


💡 O que este projeto faz
Este aplicativo funciona como uma lista de tarefas interativa no console:

Você pode adicionar novas tarefas.

Você pode listar todas as tarefas atuais com um número ao lado.

Você pode excluir uma tarefa informando o número dela.

Você pode sair do aplicativo quando terminar.

Tudo isso acontece através de um menu de opções que fica se repetindo até você escolher encerrar o programa.

🧠 Conceitos de Python que você pratica aqui
Esse projeto é ótimo para treinar:

Listas: todas as tarefas são guardadas em uma lista em memória.

Funções: cada ação (adicionar, listar, excluir) está em uma função separada.

Laço while: o menu principal roda em um loop até o usuário decidir sair.

Entrada de dados com input: o usuário interage digitando opções e textos.

Validação simples: checagem de índices e tratamento de entradas inválidas ao excluir tarefas.

Se você está estudando Python, esse é um exemplo bem concreto de como juntar esses conceitos em um programinha completo.

⚙️ Como o programa se comporta na prática
Quando você roda o script:

Aparece uma mensagem de boas‑vindas.

Em seguida é mostrado um menu com as opções:

1 – Adicionar nova tarefa

2 – Excluir tarefa

3 – Listar tarefas

4 – Sair

Você digita o número da opção desejada e pressiona Enter.

O programa executa a ação correspondente e volta ao menu.

Ao escolher 4, o app mostra uma mensagem de despedida e encerra.

Se você tentar excluir uma tarefa com um número inválido (por exemplo, um índice que não existe ou algo que não é número), o programa não quebra: ele mostra uma mensagem de erro amigável e volta ao fluxo normal.
